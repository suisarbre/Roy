# src/sim/career — 경력·재산 행위자 모델 (몬테카를로 보정)

직업마다 다르고, 같은 직업 안에서도 성격 따라 성취가 다르고, 운이 크게 끼는 "일과 돈"을 확률표 없이
굴리는 모델. 능력·성격·집안을 가진 한 사람이 학교를 마치고, 매달 일자리 제안을 받고, 더 나은 짝이면
옮기고, 해고·공장 폐쇄·장애·창업·은퇴를 겪으며, 번 돈을 성향대로 쓰고 모은다. 임금 곡선, 이직 횟수,
실직의 상처, 사업 생존, 재산 분포는 코드 어디에도 직접 적혀 있지 않다. 그 결과가 통계
(`src/sim/data/work.ts`, 출처 포함)에 수렴하도록 파라미터를 맞췄다(시뮬레이션 적률법, 결혼 모델과 같은 방식).

금액은 전부 **그 해 SSA 평균임금(AWI)의 배수**다. 1975년과 2005년의 "연봉 1.5배"가 같은 뜻이 되고,
달러가 필요하면 `averageAnnualWageAt(year)`를 곱한다.

## 실행

```bash
npm run sim:career                 # 표본 외 검증(4만 명) + 직업 분포 + 운/기질 분해 + LA 항공우주 외부 검증 + Roy (~40초)
npm run sim:career:calibrate       # 재보정(5천 명, 웜 스타트, 약 40분) → calibratedParams.ts 덮어씀
npm run sim:career:calibrate -- --fresh --gens=12   # 초기값부터 전역 탐색
npm run sim:career:calibrate -- --rake-only         # 직업 분포 비례 조정만(약 1분)
```

## 사람 (`population.ts`)

- **능력**(인지, z) — 부모 소득 순위와 상관 0.3(가정)
- **성격** — 성실성·신경성·친화성·개방성·외향성·위험 감수(각 z)
- **집안** — 부모 소득 백분위
- **학력** — 잠재변수 = 능력 + 부모 순위 × `eduParentWeight` + 0.3 성실성 + 0.15 개방성 + 잡음. 합이 정확히
  정규분포라 절단점을 해석적으로 구해 1999 CPS 35–39세 학력 분포(고졸 미만 12.4 / 고졸 34.5 / 대학 중퇴 26.2
  / 대졸+ 26.9%)를 **정확히** 만든다. 대졸자의 상위 34%(능력·성실성)가 대학원: 석사 / 로스쿨(외향성) /
  의대(능력) / 박사(개방성·능력). 대학원 종류 비율은 CPS 1999 남성 의사·법조인·교수 비율에서 역산.

## 직업 (`occupations.ts`) — 24개 클러스터

농장 일꾼 · 인부 · 식당 · 소매 · 공장 조작·조립 · **항공기 조립(항공우주)** · 트럭 · 정비·정밀가공 · 건설 기능직 ·
사무 · 군 입대 · 영업 · 경찰·소방 · 기술자 · 간호 · 교사 · 경영 전문직 · 엔지니어 · **항공우주 엔지니어** ·
기타 전문직 · 관리자(내부 승진·경력직) · 교수(박사) · 변호사(로스쿨) · 의사(의대, 레지던트 3년 뒤 자동 승급) + 자영업.

- 임금 수준(`payRatio`): **CPS 1999 남성 풀타임 주급 중앙값** ÷ 전체 남성 중앙값($618) — 검증된 값.
  "경력 20년쯤 된 평범한 사람"의 임금으로 해석한다.
- 직업 분포: 모델의 18–64세 임금근로자 직업 비율을 **CPS 1999 남성 풀타임 임금근로자 분포(21개 묶음)**에
  맞춘다 — 직업별 제안 가중치를 비례 조정(raking). 결과는 모든 묶음이 목표의 ±10% 안(작은 직업은 표본 잡음).
- 가정(원문 미확인): 학력별 입직 가중치의 **모양**, 경기 민감도, 사다리 칸, 직업 내 분산, 성격 적합도.

## 한 달 루프 (`model.ts`)

1. 학생이면 아르바이트(식당·소매). 졸업하면 고졸·대학 중퇴의 8%는 입대(4년, 가정), 나머지는 구직
2. 은퇴(55세부터, 재산이 많을수록 빨리)
3. **재직 중**, 순서대로:
   장애(나이·육체노동) → 공장 폐쇄·대량 해고(경기, 1988–95 항공우주 추가) → 해고(경기 × 직업 민감도,
   근속·성실성·좋은 짝이면 덜) → 그만둠(젊을수록, 신경성↑ 성실성↓, 입사 직후 "안 맞음") → 창업(위험 감수·
   개방성·외향성·능력, 모은 돈) → 외부 제안(더 좋으면 이직; 다른 직업이면 전환 비용 추가) → 승진(성실성·능력)
   → 관리자로 내부 승진(성실성·외향성·능력, 비친화, 학력)
4. **실업** — 제안(경기·외향성·어릴 때 집안 인맥) → 수용 기준(이전 임금에서 달마다 낮아짐). 저학력·낮은
   성실성은 구직 단념(비경제활동)으로
5. **자영업** — 폐업 위험은 사업 품질(능력·성실성 + 운)과 경기, 연차가 쌓일수록 감소. 소득 분산이 크다
6. 생일 전 달: 한 해 소득(+실업급여·장애연금·사회보장)으로 소비·저축, 자산 수익(시장 공통 충격 + 개인 충격),
   상속(집안), AWI 실질 성장으로 이월

**로그 임금** = 직업 수준 + 전역 수준 + 능력 × 직업별 능력 부하 + 성격(친화성 −, 성실성 +, 신경성 −, 판매직은
외향성 +) + 사다리 칸 + 고용주 짝 + 근속(기업 특수) + 같은 직업 연수(직업 특수) + 일반 인적자본(경력 20년에
0이 되도록 음수에서 오목하게 성장) + 영구 충격 + **기술 프리미엄 추세**(연도 × 학력: 1980–2000년대 대졸
프리미엄 상승과 저학력 상대임금 하락).

**짝의 평균**은 성격 적합도(비교우위, Roy 모형)와 입사 해의 실업률에 달렸다. 불황엔 제안 자체도 낮은 급
직업으로 기운다(하향 취업).

## 운은 어디서 들어오나

| 운 | 메커니즘 |
|---|---|
| 태어난 해 | 졸업 해 실업률 → 첫 짝·첫 직업의 급, 1980년대 초 불황, 기술 프리미엄 추세 |
| 사는 곳 | LA는 항공우주 제안 4배 → 1988–95 구조조정에 노출(폐쇄 위험·신규 채용 급감) |
| 제안 | 매달 올지 말지, 어느 직업, 짝의 질 |
| 충격 | 해고·공장 폐쇄·장애 — 근속·짝·사다리·직업 특수 자본을 한꺼번에 잃는다 |
| 승진 | 매달 굴리는 주사위(성실성·능력이 확률을 올릴 뿐) |
| 사업 | 품질의 절반 이상이 운, 연간 소득 흔들림 |
| 돈 | 시장 수익(모두가 같은 "역사"), 개인 수익, 상속 |

`npm run sim:career`의 분해: 평생 소득(22–61세) 로그의 분산 중 **학력·성격·능력·집안으로 설명되는 몫은
R² ≈ 0.38**, 나머지 0.62는 운이다.

## 보정 (`calibrate.ts`, `moments.ts`)

- 자유 파라미터 47개, 적률 66개. 측정 정의는 `moments.ts` 머리 주석(원 연구와 같은 정의로)
- 1단계 대각 진화 전략 → 2단계 좌표별 패턴 탐색 → 3단계 넬더–미드, 단계 사이마다 직업 분포 비례 조정
- **달별 난수 재시작**: 사람마다 난수열을 (사람 시드, 나이 개월)로 매달 새로 시작한다. 파라미터가 조금 바뀌어
  어떤 달의 분기(이직했나)가 달라져도 다음 달의 운은 같다. 한 번의 분기가 평생의 난수를 밀어내던 문제
  (친화성 임금 효과가 잡음에 묻혀 보정되지 않았다)가 이걸로 풀렸다 — 공통 난수가 훨씬 강해져 loss가
  47 → 19로 내려갔다
- 판정: 허용오차 1배 안 PASS, 1–2배 WARN, 2배 초과 FAIL, 정의가 구조적으로 다른 적률은 KNOWN

## 알려진 한계

1. **실직의 상처가 너무 얕다**(JLS FAIL, Kahn WARN). 모델에선 실직자가 재직 중 탐색으로 너무 빨리 사다리를
   다시 오르고, 직업을 옮기는 사람은 대부분 "더 좋아서" 옮긴다. 문헌의 설명 후보: 실직자는 불안정한 일자리에
   떨어져 다시 실직한다(일자리 안정성 사다리, Jarosch), 고용주별 임금 프리미엄(좋은 회사) 상실, 지역 노동시장
   붕괴. 다음 개선 1순위
2. 여성 없음 — 결혼 모델과 통합할 때 여성 노동 참여와 같이 넣는다
3. 재산은 1인 기준인데 목표(SCF)는 가구 — 중앙값은 맞췄지만 저축률이 가구 몫까지 떠안고 있어 결혼 통합 후
   재보정 필요. 주택(자가 보유)이 따로 없다
4. 투옥, 이민, 인종 차별 같은 1960년대생 LA 남성의 큰 변수들이 없다
5. 산업이 없고 직업만 있다(항공우주만 예외 플래그). 학력별 입직 가중치의 모양과 직업별 경기 민감도는 가정
6. 교육은 18세 전에 정해진다(재입학·야간 대학 없음)

## 게임에서 쓰는 법

```ts
const worker = buildWorker(drawWorker(rng, [1962, 1962], true), params); // LA, 1962년생
const life = simulateCareer(worker, params, rng, { keepMonths: true });
life.months  // 월별 상태·직업·임금·순자산·사건("해고", "관리자로 승진", "항공우주 구조조정으로 공장 폐쇄" …)
```

- NPC LOD: 배경 NPC는 이 함수를 한 번 돌려 인생 요약만 들고 다니고(`years`), 주요 NPC와 Roy는 월별 사건을
  실타래 트리거로 쓴다. 사건 문자열은 LLM 카메라에게 넘길 장면 힌트다
- 같은 시드 = 같은 운. `forcedFirstOccupation`으로 "첫 직장만 바꾸면?"을 비교할 수 있다(`cli.ts`의 Roy)
- 다음 단계: 결혼 모델의 `FIXED_ASSUMPTIONS`(학력 분포, 해고율, 재취업률, 장애율, 전업주부 여부)를 이 모델의
  출력으로 교체하고 둘 다 재보정
