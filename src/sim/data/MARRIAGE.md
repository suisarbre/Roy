# 결혼 도메인 — 리서치 요약과 행위자 모델 설계 함의

`marriage.ts`의 적률(calibration moments)을 어떻게 읽고, 행위자 모델을 어떻게 짜야 하는지 정리한 문서.
숫자와 출처는 전부 `marriage.ts`에 있다.

## 방침

배수 표를 메커니즘으로 쓰지 않는다. 사람마다 기질·배경·신념을 주고 → 상황을 평가하고 → 행동을 고르고
→ 행동이 관계 상태를 바꾸고 → 누적 상태에서 이혼이 터진다. 이 모델을 몬테카를로로 돌렸을 때
`MARRIAGE_MOMENTS`가 재현되도록 파라미터를 보정한다(시뮬레이션 적률법). **배수 표는 정답지다.**

## 리서치가 바꾼 것: Linda 예시 재검토

처음 가정: "Roy가 실직했는데 Linda가 전업주부이고 금전 스트레스에 민감하면 이혼 확률이 커진다."

근거를 보면 절반만 맞다.

| 근거 | 뜻 |
|---|---|
| 아내의 경제적 의존도, 가구 총소득은 이혼 위험을 거의 안 바꿈 (Killewald 2016, **null**) | "전업주부라서"가 원인이 되면 안 된다 |
| 남편이 풀타임이 아니면 연 이혼 확률 2.5% → 3.3% (Killewald 2016) | 돈보다 "생계부양자 역할" 규범 위반이 작동 |
| 해고는 이혼을 올리지만 **공장 폐쇄와 장애는 안 올림** (Charles & Stephens 2004) | 같은 소득 손실이어도 "그의 탓인가"가 갈림 |
| 금전 갈등이 가장 강한 이혼 예측 요인, 갈등을 통제하면 재정 상태는 무관 (Dew et al. 2012) | 돈 → **금전 갈등 행동** → 이혼. 행동이 매개 |
| 기질 효과는 거의 전부 만족도를 거쳐 감 (Solomon & Jackson 2014) | 기질을 해저드에 직접 곱하지 말 것 |
| 행동(r≈0.35~0.46)이 기질(0.20)이나 스트레스 사건(0.14)보다 안정성을 강하게 예측 (Karney & Bradbury 1995) | 행동 층이 모델의 중심 |

그래서 Linda의 경로는 이렇게 된다.

```
Roy 실직
  → Linda의 평가: 귀인(해고=그의 탓일 수 있음 / 공장 폐쇄=아님)
                 × 전통성(생계부양자 규범) × 신경성·금전 불안
  → 행동 선택: 금전 갈등(대립) / 회피 / 지지
  → 만족도 ↓ (대립이 반복될 때)
  → 헌신 = 만족도 + 투자(자녀·집·세월) − 대안의 질, 시대 장벽 반영
  → 헌신이 문턱 아래 + 대안 존재 → 별거/이혼
```

전업주부 여부는 이 경로에서 **스트레스를 키우는 쪽**(수입 대안 없음)과 **장벽을 키우는 쪽**(떠나면 생계
막막)에 동시에 걸려 대략 상쇄되어야 한다. 그래야 Killewald의 null이 재현된다. 이게 "예시가 틀렸다"가
아니라 오히려 더 좋은 드라마다: 불안한 Linda는 싸우지만 떠나지 못하고, 그 긴장이 장면이 된다.

## 최소 행위자 구조 (제안)

- **기질(고정, 표준정규 z점수)**: 신경성, 성실성, 친화성, 개방성, 금전 불안, 전통성. 성격 5요인은
  근거가 있는 4개만 우선 쓴다(외향성은 이혼 예측력 근거 약함).
- **배경**: 학력(4단계 — 효과는 대졸에서만 크게 꺾이는 계단형), 부모 이혼 여부, 결혼 나이.
- **관계 상태(부부가 공유하는 한 객체)**: 만족도, 누적 갈등, 투자.
- **행동 메뉴**: 대립, 회피, 지지, 도움 요청, (드물게) 외도, 떠남. 기질 가중 효용의 로짓 선택.
- **시대**: `californiaDivorceRegimeAt` — 1970년 전후로 떠남의 비용이 달라짐.

## 보정 목표 체크리스트

행위자 모델이 통과해야 할 것(하네스 테스트로 고정할 것):

1. 첫 결혼 5년/10년 해체율 0.20/0.33, 재혼 해체 0.23/0.39
2. 학력별 이혼 — **계단형** (고졸 미만~대학 중퇴 ≈ 50%, 대졸 27%, 남성)
3. 결혼 나이: 32세까지 1살당 이혼 오즈 약 −11%
4. 남편 비풀타임 연 이혼 확률 3.3% 대 2.5%
5. 아내 경제 의존도 효과 ≈ 0 (**null**)
6. 해고 후 1~3년 이혼 오즈 약 1.36배, 공장 폐쇄 ≈ 1.0 (**null**), 장애 ≈ 1.0 (**null**)
7. 금전 갈등 행동을 끄면 재정 상태 효과가 사라짐 (**매개 검증**)
8. 부모 이혼 오즈비 1.7~1.9
9. 신경성 1SD당 해체 오즈 약 1.36, 효과가 만족도를 통해서만 감
10. 1970년 무과실 이후 5년간 이혼율 약 40% 증가, 1980년 정점 (NPC 부모 세대에서)

파라미터 수보다 적률 수가 많아야 과적합이 안 된다 — 위 목록만으로 수치 적률이 20개 이상이다.

## 확인 못 한 것 / 버린 것

- **Bramlett & Mosher (2002) 특성별 표는 폐기했다.** 요약 도구가 PDF 표를 읽지 못하고 그럴듯한 숫자를
  지어냈다(전체 5년 해체율 16.5%, 재혼 32.7% — 같은 보고서 보도자료의 20%, 54%와 모순). 결혼 나이별·
  종교별·원가족별 10년 해체율이 필요하면 원문 PDF를 사람이 직접 열어서 옮길 것.
- **투자 모델 메타분석(Le & Agnew 2003)의 상관 크기**: 원문 접근 실패. 구조만 쓴다.
- **Charles & Stephens 계수의 모형**(로짓인지)은 오즈비 환산 전 재확인.
- **Solomon & Jackson 데이터셋 국가**는 재확인.
- 연도별 이혼율은 기준점 4개(1900, 1980, 2018, 2022)만 확인했다. 중간값은 보간하지 않았다.
