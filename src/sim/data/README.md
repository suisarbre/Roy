# src/sim/data — 세계 데이터와 검증 타깃

시뮬레이션이 "1962년생 LA 노동계급 남성이 실제로 산 세계"와 맞게 돌아가도록 하는 사실 테이블과,
3단계 헤드리스 하네스가 비교할 통계 타깃을 모아둔 곳이다. 전부 순수 데이터 + 순수 함수라
LLM이나 브라우저 없이 Node에서 바로 쓸 수 있다.

## 파일

| 파일 | 내용 | 범위 | 1차 출처 |
|---|---|---|---|
| `series.ts` | 연도→값 표 조회기(보간·외삽 규칙) | — | — |
| `cpi.ts` | CPI-U 연평균 + 달러 환산(`priceIn`, `convertDollars`) | 1955–2025 | BLS CUUR0000SA0 |
| `wages.ts` | SSA 평균임금지수, 연방·CA 최저임금 | 1951–2024 / 1952–2026 | SSA AWI, DOL WHD, CA DIR |
| `unemployment.ts` | 미국 실업률 연평균 | 1955–2025 | BLS CPS cpsaat01 |
| `housing.ts` | 30년 모기지 금리, 신축 주택 가격 중앙값, 총임대료 중앙값, Roy 코호트 자가 보유율 | 1971–2025 / 1963–2024 / 센서스 연도 + 2023 / 25세~ | Freddie Mac PMMS, Census SOC, Census HCH·ACS, Census HVS Table 15 |
| `lifeTables.ts` | 코호트 생명표 q(x), 월 사망확률, 사망 나이 샘플링 | 1930·1940·1960·1970·1990 코호트, 남녀, 0–119세 | SSA Actuarial Study 120 Table 7 |
| `eraFacts.ts` | NBER 경기 침체 기준일, 징병 등록(Selective Service) 사실 | 1969–2020 / 1973–1987 | NBER, Proclamation 4771 |
| `validationTargets.ts` | 하네스 검증 타깃(사망, 결혼·이혼, 일자리, 출산, 자가 보유) | NLSY79(1957–64년생) 중심 | BLS NLSY79, SSA |

각 파일 머리 주석에 URL, 대조한 값, 외삽 가정이 있다.

## 검증 방법 (이번 작업에서 한 것)

- **CPI**: BLS 월별 원자료(GitHub `datasets/cpi-us` 미러)를 연평균 → BLS 공표 연평균과 대조.
- **생명표**: 옮긴 q(x)로 기대수명을 재계산 → SSA 공표값과 전 코호트·남녀 0.02년 이내 일치.
- **나머지 시계열**: 대표 연도 3개 이상을 알려진 공표값과 대조.
- `tsc -b`, `oxlint` 통과. 헬퍼 함수 스팟 체크(예: 1962년생 남성 기대수명 74.27년, 65세 생존 78.6%).

## 게임용 가정 (사실이 아님 — 튜닝 대상)

| 항목 | 가정 |
|---|---|
| CPI 2026년 이후 | 연 2.5% |
| 평균임금 2025년 이후 | 연 3.5% |
| 실업률 2026년 이후 | 5.0%로 반감기 3년 평균 회귀 |
| 모기지 1962–1970 | 1971년 값 유지(PMMS 시작 전) |
| 신축 주택 가격 2025년 이후 | 연 4% |
| 월세 사이 연도 | 센서스 연도 사이 기하 보간, 2024년 이후 연 3.5% |
| 최저임금 표 이후 | 마지막 값 유지 |

## 알려진 공백 / 다음에 채울 것

- **사인(死因) 분포**: 연령대별 주요 사인 비율을 CDC WISQARS 표에서 가져오려 했으나, 추출 결과
  연령대 열이 어긋나 신뢰할 수 없어 넣지 않았다. 사인 템플릿(`textTemplates.ts`의 급사 원인)을
  나이에 맞게 고르려면 CDC NCHS LCWK 표를 사람이 직접 받아 넣는 게 안전하다.
- **LA/캘리포니아 지역 보정**: 집값·월세·실업률은 전국 값이다. LA는 1970년대 후반 이후 집값이
  전국보다 크게 높았다 — 지역 배수를 파라미터로 둘 것(수치는 미확인).
- **교육 수준 분포**: Roy 코호트의 최종 학력 분포(고졸/대졸 비율)는 아직 없다. 결혼·이혼·일자리
  타깃에 교육별 값이 있으니, 하네스에서 교육을 샘플링하려면 이 분포가 필요하다.
- **CA 최저임금의 1970년대 이전 적용 범위**(여성·미성년자 한정 여부)는 원문 미확인.
- **1960년대 모기지 금리**: PMMS 이전이라 미포함.

## 사용 예

```ts
import { priceIn, averageAnnualWageAt, monthlyDeathProbability, isInRecession } from '../data';

priceIn(1978, 4.5);                                // 2024년 $4.50짜리 햄버거의 1978년 가격
averageAnnualWageAt(1985) * 0.8;                   // 평균의 80%를 버는 공장 노동자 연봉
monthlyDeathProbability(1962, 'male', 58, 1.4);    // 만성질환으로 위험 1.4배인 58세 Roy의 이번 달 사망확률
isInRecession({ year: 1991, month: 1 });           // 해고 압력 가중치
```
