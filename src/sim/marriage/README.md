# src/sim/marriage — 결혼·출산 행위자 모델 (몬테카를로 보정)

결혼과 이혼을 확률 배수로 굴리지 않고, 기질·배경을 가진 두 사람의 **행동**이 쌓여서 이혼이
**창발**하게 만든 모델. 출산도 같은 루프 안에서 부부의 결정으로 일어나고, 자녀는 다시 결혼에
영향을 준다. 문헌 통계(src/sim/data/marriage.ts, fertility.ts)는 메커니즘이 아니라 몬테카를로 결과가
맞춰야 할 정답지로만 쓴다(시뮬레이션 적률법). 근거와 설계 배경은 `src/sim/data/MARRIAGE.md`.

**경력 모델과 통합됨**: 두 사람은 `src/sim/person` 프로필(능력·성격·집안·학력)이고, 남편의 실직·재취업·
장애는 그 자신의 경력 궤적(`src/sim/career`)에서, 아내의 취업·전업·복귀는 같은 달에 한 칸씩 진행하는
아내의 경력에서 나온다. 출산하면 아내가 일을 떠날 수 있고(전통성·학력·남편 소득), 아이가 크거나 이혼하면
돌아온다. 결혼·출산 파라미터와 여성 노동 공급 파라미터를 한 번에 보정했다(남성 경력은 고정).

## 실행

```bash
npm run sim:marriage                 # 표본 외 검증 + 매개 검증 + Linda 시나리오 + 통합 이야기 (4만 쌍 약 2분, --n=20000 권장)
npm run sim:marriage:calibrate       # 통합 재보정(4천 쌍, 웜 스타트, 약 1시간 20분) → calibratedParams.ts 덮어씀
npm run sim:marriage:calibrate -- --fresh --gens=10   # 초기값부터 전역 탐색
npm run sim:marriage:calibrate -- --refine-only       # 드문 사건 정밀 조정만
```

## 한 달 루프 (`model.ts`)

1. 사망(코호트 생명표)·관측 종료(남편 55세) 확인
2. 남편 고용 — 남편의 경력 궤적에서 그 달의 상태(취업 / 실업·구직 단념 / 장애)와 충격(해고 / 공장 폐쇄 /
   장애)을 읽는다. 궤적은 결혼과 무관하게 정해지므로 보정 내내 한 번만 계산해 캐시한다
   아내 — 지난달 아내의 경력 상태(전업이면 외벌이 긴장·금전 위협 증폭·떠나는 비용)를 이번 달 평가에 쓰고,
   출산 결정 뒤 아내의 경력을 한 칸 진행한다(출산 → 이탈 가능, 결혼한 실업 여성 → 가사 가능, 이혼 → 복귀 쪽)
3. **평가** — 각자의 금전 스트레스
   - 만성 경제 긴장: 학력(대졸에서 계단식으로 뚝 떨어짐) + 외벌이 가구 긴장
   - 실업 위협: 금전 불안으로 증폭, 전업주부면 1.5배, 장애는 소득 대체로 0.4배
   - 아내의 비난: 해고는 "그의 탓"일 수 있음(전통성으로 증폭), 공장 폐쇄는 그 0.1배, 장애는 0
   - **출산**: 희망 자녀 수(학력·전통성)에 못 미치면 나이별 가임력 × sigmoid(속도 + 헌신 − 금전
     스트레스 − 아내 일의 기회비용)로 출산, 채웠으면 계획 외 출산만(3%). 흔들리는 부부는 미룬다(Lillard & Waite 1993)
   - 양육 스트레스: 6세 미만 자녀 1명당 스트레스 가산
4. **행동** — 지지/중립/대립 로짓 선택. 신경성·스트레스는 대립으로, 친화성·성실성·연민은 지지로
5. **만족도**(부부 공유 객체) — 지지 +, 대립 −, 대립은 설정점을 깎는 흉터를 남김, 신혼 가산에서 출발,
   출산한 달에 하락
6. **헌신**(각자) = 만족도 + 투자(결혼 연수 + 자녀 결속) − 대안(젊음·개방성) + 장벽(전통성·부모 이혼·전업주부).
   자녀 결속은 3세 미만일 때 1.6배, 6세까지 1배, 이후 18세에 0.1배까지 줄어든다("아기가 어릴 때는 떠나지 않는다")
7. **떠남** — 월 확률 sigmoid(절편 − 헌신). 한 명이라도 떠나면 이혼

이혼 확률은 코드 어디에도 직접 적혀 있지 않다. 기질은 행동·대안·장벽을 통해서만 작동한다.

| `FIXED_ASSUMPTIONS` | 남은 가정 | 결혼 나이(학력별), 동류혼 0.6, 비혼 여성 15%, 가임력 곡선. 시나리오 전용 재취업률 |

모델의 출력이다. 여성 직업 분포는 CPS 1999 여성 풀타임 분포에 비례 조정한다(남성과 같은 방식).

## 보정 (`calibrate.ts`, `moments.ts`)

- 목적 함수: 적률 31개의 표준화 제곱 오차 합(각 적률의 허용오차로 나눔)
- 공통 난수: 모든 후보가 같은 부부 집합(seed=1, 1만 쌍)을 씀
- 1단계 대각 진화 전략(전역) → 2단계 좌표별 패턴 탐색(국소) → 3단계 넬더–미드(여러 축 동시 이동)
  → 4단계 드문 사건 정밀 조정(장애처럼 드문 사건에 묶인 파라미터를 다른 시드 3만 쌍 × 2로 이분법 재조정)
- 측정 정의는 `moments.ts` 머리 주석(카플란–마이어, 층별 표준화 위험비, 단변량 로지스틱)
- 판정(`cli.ts`): 허용오차 1배 안 PASS, 1~2배 WARN, 2배 초과 FAIL. 허용오차가 원 연구의 불확실성
  (표준오차, 연구 간 범위)이라 1~2배는 원 추정치의 신뢰구간 근처로 본다.
- **KNOWN(알려진 격차)**: 모델과 목표의 정의가 구조적으로 어긋나는 적률(`knownGap` 필드). 보정 loss에는
  그대로 들어가지만 검증에서는 FAIL 대신 이유와 함께 표시한다. 허용오차를 몰래 넓히지 않기 위한 장치.

### 알려진 한계

- **여성 실업이 전반적으로 높다(1–2배 허용오차).** 여성의 해고·그만둠·제안은 남성 경력 파라미터를 그대로
  쓰고, "결혼한 여성은 실업 대신 가사로"와 비경제활동 배수만 여성 전용이다. 여성의 이직이 실업을 거치지
  않고 노동시장 밖으로 가는 경로(그만둠 → 가사)가 따로 있어야 할 것 같다
- **대졸 남성의 55세까지 이혼이 높다(0.33 대 0.27).** 통합 전엔 대졸 남성의 실직이 가정값으로 드물었는데,
  경력 모델에선 대졸도 실직·이직을 꽤 겪는다
- **여성 NPC의 경력은 아직 게임에 없다.** 여성의 경력은 가구 상황(결혼·자녀)을 매달 받아야 하는데, 게임
  NPC의 결혼은 아직 `lifeCourse.ts`의 기저 해저드다 — NPC 결혼을 이 모델로 옮기는 게 다음 단계
- **결혼 밖 출산이 없다(KNOWN 2개).** 미혼 출산, 결혼 전 임신, 이혼 후 새 관계의 출산이 없어서 자녀 1명이
  과대하고 고졸 미만 여성의 자녀 수가 과소하다. 재혼 모델과 결혼 전 임신("급히 한 결혼")이 생기면 해소될 것.
- **대졸 여성의 무자녀(21% 대 27%)가 모자란다.** 아내 일의 기회비용으로 18% → 21%. 남은 부분은 결혼 밖
  출산이 없는 것과 같은 뿌리(목표는 모든 여성, 모델은 첫 결혼 안의 출산).
- **실직 직후 출산이 앞당겨지는 현상**(Lindo 2010)은 메커니즘이 없다. 완결 출산 변화(−0.10)만 맞춘다.
- **드문 사건의 위험비는 표본오차가 크다.** 1만 쌍 보정에서 장애 관련 파라미터가 우연에 맞춰졌다(아래).
- 외도·재혼·결혼 전 관계·결혼 밖 출산은 공유 세계(`src/sim/world`)가 이 모델의 `stepUnionMonth`를 감싸서 다룬다. 배우자 기질 상관(동류혼)은 아직 없다.

## 보정 과정에서 드러난 것 (모델이 가르쳐준 것)

경력 모델과 통합하면서:

- **전업주부 효과를 월 단위로 재면 자녀가 섞인다.** 전업은 어린 자녀가 있는 달에 몰려서, 층을 연차 × 학력 ×
  결혼 나이로만 나누면 아내 전업 위험비가 0.69(자녀의 이혼 억제 효과가 섞임)였다. 자녀 수·막내 6세 미만
  여부를 층에 넣자 0.80 → 보정 후 1.03
- **10년 해체율이 저절로 맞았다(0.304 → 0.317).** 가정값 시절엔 남편 실업이 평균 6.7개월짜리 한 종류였는데,
  경력 모델에선 저학력 남편이 반복해서 실직하고 오래 쉰다 — 결혼 5~10년 차의 긴장이 커진 것으로 추정(검증 안 함)
- **공장 폐쇄 null도 저절로 맞았다(1.10 → 0.88).** 해고와 달리 공장 폐쇄에는 근속 보호가 없어서 장기근속자 —
  대개 결혼이 오래된 안정된 부부 — 비중이 크고, 그만큼 위협이 흡수되는 것으로 추정(검증 안 함)
- **결혼 모델에도 달별 난수 재시작을 넣었다**(경력 모델에서 배운 것). 아내가 이번 달 일을 떠났나 같은 분기가
  달라져도 다음 달의 운은 같다

- **연차로만 표준화한 위험비는 교란된다.** 해고가 저학력·조혼 부부에 몰려 있어서, 금전 경로를
  끊어도 실업 위험비가 1.15로 남았다(매개 검증으로 발견). 원 연구들은 공변량을 통제한 추정치라
  위험비를 (연차 × 학력 × 결혼 나이대) 층별로 표준화하도록 바꿨다.
- **4천 쌍 보정은 과적합됐다.** 보정 loss 9.5가 표본 외에서 18.8로 두 배. 드문 사건 적률이 seed
  1의 우연에 맞춰진 것. 1만 쌍 보정 + 4만 쌍 검증으로 바꾸자 12.9 → 13.5로 일치.
- **저장 파일에 고정 파라미터가 빠져 NaN이 된 버그**: 모든 행동이 조용히 "중립"이 되어 기질 효과가
  사라졌다. 이제 calibratedParams.ts는 전체 파라미터를 저장한다.

- **해체 시점의 모양은 투자 하나로 안 맞는다.** 투자를 올리면 10년 해체율은 맞지만 5년이 너무
  높아진다. 실제 이혼은 신혼 1~2년에 적고 3~8년 차에 몰린다 → 신혼 효과 크기를 자유 파라미터로 둠.
- **"비풀타임"(Killewald)과 "장애 효과 없음"(Charles & Stephens)은 한 집단에서 동시에 맞출 수 없다.**
  장애 개월이 비풀타임 안에 섞이면 장애를 1로 맞추는 순간 비풀타임 위험비가 1.07로 떨어진다.
  Killewald의 비풀타임은 대부분 실업·시간제라 판단해, 비풀타임 위험비는 **실업 개월로만** 잰다.
- **공장 폐쇄 null은 경계에 걸린다.** 비난 없이 금전 위협만으로도 위험비가 1.1~1.2 나온다. 원 연구의
  "유의하지 않음"은 신뢰구간이 넓다는 뜻일 수 있어 허용오차를 넉넉히 뒀지만, 가장 먼저 흔들리는 지표.
- **학력 효과의 "평평한 구간"은 따로 파라미터가 필요 없었다.** 고졸 미만~대학 중퇴의 긴장 차이가
  첫 보정에서 ≈0으로 수렴해 고정했다(결혼 나이 차이가 평평함을 대부분 설명).
- **표본 크기**: 장애·공장 폐쇄는 드문 사건이라 4천 쌍 보정에서 표본오차가 크다. 표본 외 검증은 4만 쌍.

출산을 넣으면서 드러난 것:

- **"평생 실직 여부"로 나눈 출산 비교는 노출 기간 편향이다.** 오래 결혼한 부부가 실직도 출산도 많이 겪어서
  실직 부부가 자녀가 0.66명 **많게** 나왔다. Lindo처럼 사건 기준(실직 순간의 자녀 수·나이·학력이 같은
  대조 부부와 그 이후 출산 비교)으로 바꾸자 +0.02 → 보정 후 −0.01.
- **자녀 결속을 영구히 쌓으면 방향이 뒤집힌다.** 큰 자녀가 어린 자녀보다 이혼을 더 막았다(0.72 대 0.90) —
  큰 자녀가 있는 가족은 대개 자녀가 여럿이라 결속이 합산되기 때문. 문헌(어린 자녀일수록 보호)과 맞추려면
  결속이 자녀 나이에 따라 줄고, 영아기에 더 강해야 했다.
- **드문 사건 파라미터는 보정 표본의 우연에 맞춰진다.** 1만 쌍 보정 후 연민 파라미터가 2.46까지 가서, 다른
  시드 3만 쌍 세 개에서 장애 위험비가 일관되게 0.64~0.72(목표 1.0)였다. 보정기에 4단계(대규모 표본 이분법
  재조정)를 추가 → 0.15로 조정, 표본 외 1.02.
- **희망 자녀 수의 개인차가 크면 분포가 퍼진다.** 표준편차 1.2에선 2명이 23%, 4명 이상이 20%였다. 미국의
  강한 두 자녀 규범을 반영해 0.9로, 계획 외 출산을 6%에서 3%로 줄였다.

## 게임에서 쓰는 법

NPC의 결혼·출산·이혼은 이 모델로 만든다: `src/sim/person/lifeStory.ts`가 NPC 프로필에 배우자를 붙여 부부를
굴리고(사망은 끄고 생명표로 따로), 그 결과가 NPC 체크인 사실과 장면 묘사로 간다. Roy 자신의 결혼은 아직 이
모델에 연결되지 않았다 — 플레이어의 행동을 지지/대립으로 읽어 들이는 입력 해석(IR)이 붙어야 한다.

### MonthRecord (장면 재료)

`simulateCouple`의 `MonthRecord`에는 매달 두 사람의 행동, 금전 갈등 여부, 만족도, 헌신이 있다.
편집기(스토리텔러)가 볼 사건 후보가 자연스럽게 나온다: "대립이 3개월 연속", "헌신이 문턱 근처",
"실직 후 첫 금전 갈등" 등. 장면은 이 기록을 LLM에게 넘겨 렌더링하면 된다 — LLM은 판정하지 않는다.
