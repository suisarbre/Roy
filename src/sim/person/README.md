# src/sim/person — 한 사람(기질·배경)과 도메인 모델 사이의 연결

Roy든 NPC든 같은 `PersonProfile` 하나를 갖는다: 능력, 성격(성실성·신경성·친화성·개방성·외향성·위험 감수),
금전 불안, 전통성, 부모 소득 순위, 부모 이혼, 학력(석사·박사·전문 학위까지), LA 거주, 그리고 모든 운을
재현하는 `lifeSeed`. 도메인 모델은 전부 이 프로필 하나를 읽는다.

| 파일 | 역할 |
|---|---|
| `profile.ts` | `sampleProfile(seed, {sex, birthYear, traits?})` — 경력 모델의 교육 잠재변수로 학력까지 뽑는다. `toWorker`(경력 모델 입력), `toSpouse`(결혼 모델 입력) |
| `lifeStory.ts` | `buildLifeStory` — 한 사람의 인생 이야기: 이 사람을 주인공으로 넣은 공유 세계(`src/sim/world`)를 85세까지 굴린다. 만남·연애·동거·결혼·이혼·재혼·결혼 밖 출산·외도가 세계의 규칙대로 나오고, 경력은 그 세계 안에서 한 달씩(여성은 가구 상황을 받아 출산 후 이탈·복귀). lifeSeed로 완전히 재현되고 캐시만 한다 |
| `careerTrack.ts` | 이야기를 날짜로 들여다보는 창: `careerStatusAt`(직업·연봉·순자산), `careerEventsBetween`, `familyEventsBetween`, `familyStatusAt`, 사건별 현저성·도메인, 영어 사실 문장, `storyOptionsFor`(관계 유형 → 옵션) |
| `temperament.ts` | 성격 → 실타래 관심 배분(`personalityPolicy`)과 인내심, LLM용 성격 형용사(`describeTraits`) |

## 연결된 곳

- `sim/npc`: `NpcSimRecord.profile`. `createNpcSimRecord`에 프로필만 주면 기질(temperament)이 성격에서
  만들어진다. `catchUpNpc`는 프로필이 있으면 인생 이야기를 진실로 쓴다 — 결혼·출산·이혼·사별·취업을 이야기에서
  가져와 lifeCourse 카운터에 반영하고(`lifeCourse.ts`의 결혼·취업 기저 해저드는 안 씀, 자가 보유만 남음),
  결혼하면 결혼 실타래를 판에 올리고, 경력·가족 사건을 실타래 이벤트로 내보내 `collision.ts`가 고르게 한다
- `game`: NPC가 생성될 때(`npcImportance.createNpc`) 프로필을 받는다. 체크인(`npcCheckIn.ts`)은 경력 사건을
  "공장이 문을 닫아 일자리를 잃었다", "아이가 태어났다" 같은 구체적 사실로 날짜 순서대로 기억 그래프에 넣는다.
  장면 프롬프트에는 `npcSketch.ts`의 인물 한 줄(성격·학력·지금 하는 일과 연봉·혼인·자녀)이 들어간다 — LLM은
  시뮬레이션이 정한 사람을 연기만 한다

## 설계 가정(보정 안 된 값)

- 성격 → 실타래 도메인 가중치(`DOMAIN_TRAIT_WEIGHTS`)와 인내심 공식: 비교할 통계가 없어 설계로 정했다
- 학력 분포는 1960–64년생 기준 — 1930년대생 부모 NPC는 실제보다 학력이 높게 나온다
- 가족 사건 종류: 결혼(`nth` = 몇 번째), 동거, 이혼, 동거 해체(`separated`), 사별, 출산(`nonmarital`), 내 외도가
  들킴, 배우자의 외도를 알게 됨. 들키지 않은 외도는 사건이 아니다(이야기 안에서는 비밀)
- **Roy의 배우자 NPC**: 그 결혼은 플레이어의 것이라 가족 사건을 만들지 않는다. 경력만 — 여성이면 "결혼 중, 자녀
  정보 없음, 배우자 소득 평균"이라는 가구 상황으로 굴린다(Roy의 자녀·소득이 게임 상태에서 이야기로 아직 안 온다)
- **Roy의 부모 NPC**는 "짝 찾는 힘"을 크게 올려 거의 반드시 짝을 찾게 하지만(`forceMarried`), 그 결혼의 출산이
  Roy와 연결돼 있지 않다
- 배우자가 결혼 모델 안에서 사망하지 않게 하고(사망은 생명표로 따로), 사별 뒤에도 아내의 경력은 그 달까지
  "결혼 중" 가구 상황을 받은 채로 계산된 것을 쓴다 — 사별 이후 몇 달의 노동 공급이 조금 어긋날 수 있다
- `npm run sim:npc` 6절: 1960년생 NPC 남녀 각 600명의 이야기 요약(결혼 경험 남 86% · 여 87%, 첫 결혼 이혼
  약 40%, 평균 자녀 남 2.1 · 여 2.1, 40세 취업 남 84% · 여 72%) — 연결이 맞는지 보는 용도, 정밀 검증은 각 모델의 CLI
